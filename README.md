# 🐍 Curso de Python

Este repositório reúne as anotações e práticas desenvolvidas durante um curso de Python. A ideia é simples: servir como um caderno de estudos, onde cada arquivo corresponde a uma aula específica, permitindo acompanhar a evolução do aprendizado e revisar os conceitos sempre que necessário. 📝

### 🎯 Sobre o Curso

O material está organizado de forma progressiva, começando pelos conceitos básicos da linguagem e avançando aos poucos. Cada aula tem seu próprio arquivo numerado, então dá pra seguir na ordem e ir acompanhando o desenvolvimento dos tópicos sem se perder. 🚀

### 📂 Organização

A estrutura é bem direta:
- 📜 Os arquivos vão de 01_aula.py até 09_aula.py, na mesma ordem das aulas.
- 🧪 A pasta exercicios/ reúne práticas extras pra quem quiser treinar mais.

### 🚀 Como Usar

- Clone o repositório:
git clone https://github.com/sebrian-dev/Curso-PYTHON.git
- Abra os arquivos no seu editor de código preferido (VS Code, PyCharm, etc.) 🖥️
- Execute os scripts na ordem numérica. 🔢
- Depois de cada aula, dá uma olhada na pasta exercicios/ pra fixar melhor. 💪
